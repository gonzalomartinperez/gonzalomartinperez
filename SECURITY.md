# Reporting a security concern

This repository contains public profile Markdown and static visual assets. It does
not run the portfolio, assistant API or backoffice. Application-specific concerns
belong with the affected repository and its reporting instructions.

For a concern involving this profile, email
[gonzalomartinperez2002@gmail.com](mailto:gonzalomartinperez2002@gmail.com) with
`GitHub profile security report` in the subject. Include the affected file or public
URL, a short description and safe reproduction steps. Do not post credentials,
personal information or exploit details in public issues or pull requests.

If you notice an exposed secret, identify its location privately without copying
the value. Do not test the credential, contact its provider or change account
settings. Investigation and any credential response require the owner's authority.

Please avoid intrusive testing of linked sites or third-party services. Reporting
a concern does not grant permission to access private data or disrupt a service.
This personal repository does not offer a bounty, guaranteed response time or a
version-support commitment.
